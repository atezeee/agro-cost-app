# AgroCost — веб-приложение для расчёта стоимости агротехнических работ

Стек: Go, PostgreSQL, HTML/CSS/JavaScript. Версия подготовлена под деплой на Vercel.

## Что реализовано

- выбор федерального округа;
- выбор культуры;
- выбор агротехнической операции;
- выбор техники, подходящей для выбранной агроработы;
- выбор режима техники: собственная техника или аренда;
- расчёт затрат по строкам;
- автоматический подбор региональной цены из базы цен;
- история расчётов;
- регистрация и вход по желанию;
- автоматический парсинг всех активных источников по расписанию Vercel Cron;
- устойчивость к сбоям внешних сайтов: если источник недоступен, ошибка пишется в журнал, а расчёт продолжает работать по последней сохранённой цене.

## Автоматический парсинг без кнопок

Пользователь не запускает парсинг вручную. В `vercel.json` настроен cron:

```json
{
  "path": "/api/cron/parse-prices",
  "schedule": "0 */6 * * *"
}
```

Это означает автоматическое обновление цен каждые 6 часов. Маршрут `/api/cron/parse-prices` перебирает все активные источники из таблицы `price_sources` и пытается получить данные через соответствующий парсер: `csv`, `json`, `html_regex` или `auto`.

Если сайт недоступен, изменил HTML-разметку или не отдаёт данные в подходящем формате, приложение не падает. Ошибка сохраняется в `parser_logs`, остальные источники продолжают обрабатываться.
- подтверждение цен администратором;
- экспорт расчётной ведомости в Excel/PDF.
