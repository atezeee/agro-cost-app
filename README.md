# AgroCost — веб-приложение для расчёта стоимости агротехнических работ

Стек: Go, PostgreSQL, HTML/CSS/JavaScript. Версия подготовлена под деплой на Vercel.

## Что реализовано

- выбор федерального округа;
- выбор культуры;
- выбор агротехнической операции;
- выбор техники, подходящей для выбранной агроработы;
- выбор режима техники: собственная техника или аренда;
- расчёт затрат по строкам;
- автоматический подбор региональной цены из базы цен;
- история расчётов;
- регистрация и вход по желанию;
- автоматический парсинг всех активных источников по расписанию Vercel Cron;
- устойчивость к сбоям внешних сайтов: если источник недоступен, ошибка пишется в журнал, а расчёт продолжает работать по последней сохранённой цене.

## Автоматический парсинг без кнопок

Пользователь не запускает парсинг вручную. В `vercel.json` настроен cron:

```json
{
  "path": "/api/cron/parse-prices",
  "schedule": "0 */6 * * *"
}
```

Это означает автоматическое обновление цен каждые 6 часов. Маршрут `/api/cron/parse-prices` перебирает все активные источники из таблицы `price_sources` и пытается получить данные через соответствующий парсер: `csv`, `json`, `html_regex` или `auto`.

Если сайт недоступен, изменил HTML-разметку или не отдаёт данные в подходящем формате, приложение не падает. Ошибка сохраняется в `parser_logs`, остальные источники продолжают обрабатываться.

## Деплой на Vercel

1. Загрузить проект на GitHub.
2. Создать проект на Vercel.
3. Указать переменные окружения:

```text
DATABASE_URL=postgres://...
RUN_MIGRATIONS=true
AUTH_REQUIRED=false
SESSION_SECRET=любая-длинная-строка
DEFAULT_FEDERAL_DISTRICT=ЮФО
```

Для базы можно использовать Neon, Supabase, Render PostgreSQL или другой внешний PostgreSQL. Vercel сам по себе не заменяет PostgreSQL-базу.

## Важное ограничение Vercel

Vercel запускает Go-код как serverless function. Это значит, что внутри приложения нельзя держать бесконечный фоновый цикл `for { parse(); sleep(...) }`, как на обычном VPS или Render. Поэтому автоматическое обновление сделано правильно для Vercel — через Cron Job, который периодически вызывает API-маршрут.

## Что парсится

В базе есть активные источники:

- демонстрационный CSV — гарантированно работает и наполняет окружную ценовую базу;
- СПбМТСБ — источник для топлива и удобрений;
- ЕМИСС / Росстат — официальные региональные показатели;
- Agroserver — коммерческие предложения по семенам, удобрениям, СЗР, технике и услугам;
- Поле.рф — аграрный маркетплейс.

Архитектура поддерживает все эти источники. Но реальные сайты без API могут менять HTML, блокировать запросы или требовать настройку конкретной страницы категории. Поэтому стабильнее всего работают CSV/JSON-источники и те сайты, где есть открытая выгрузка.
