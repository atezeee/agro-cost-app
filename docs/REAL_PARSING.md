# Реальный интернет-парсинг цен

В этой версии подсистема цен больше не ограничивается встроенной демонстрационной таблицей. Cron `/api/cron/parse-prices` автоматически запускает активные источники:

1. `Agroserver — коммерческие предложения` — parser_type `agroserver_bundle`, URL `internet:agroserver_bundle`.
   - открытые страницы категорий Agroserver;
   - дизельное топливо;
   - семена пшеницы, ячменя, подсолнечника, кукурузы;
   - аммиачная селитра, карбамид, азофоска NPK;
   - гербициды, фунгициды, инсектициды;
   - аренда/услуги техники по страницам агроработ.

2. `HeadHunter — зарплаты механизатора` — parser_type `hh_salary`, URL `internet:hh_mechanizator`.
   - открытый API hh.ru;
   - вакансии механизатора по Волгоградской области;
   - медианная месячная зарплата пересчитывается в руб./ч.

3. `Демонстрационный CSV` — parser_type `csv`, URL `builtin:regional_prices`.
   - это резервный источник;
   - он нужен, чтобы расчёты не ломались, если внешний сайт недоступен или изменил разметку;
   - интернет-цены имеют более высокий приоритет, поэтому при успешном парсинге используются они.

## Почему не все сайты включены активными

СПбМТСБ, Поле.рф и ФГИС Сатурн оставлены в реестре, но не включены как основной парсер:

- СПбМТСБ требует точного открытого URL выгрузки/индикатора;
- Поле.рф может отдавать данные через JavaScript или требовать авторизацию;
- ФГИС Сатурн — справочная система прослеживаемости СЗР, а не источник коммерческих цен.

## Как проверить

Открой URL:

```text
https://<твой-домен>/api/cron/parse-prices
```

После выполнения в таблице `parser_logs` должны появиться строки со статусом `success`, `partial`, `empty` или `error`.

В интерфейсе цены должны отображать источник `Agroserver — коммерческие предложения` или `HeadHunter — зарплаты механизатора`, если интернет-парсинг прошёл успешно. Если сайт недоступен, будет использоваться резервный источник `Демонстрационный CSV`.

## Обновление парсера Agroserver

Парсер Agroserver больше не обращается к несуществующим адресам вида `/b/dizelnoe-toplivo/`. Вместо этого используются реальные разделы каталога:

- `/gsm/` — горюче-смазочные материалы;
- `/semena/` — семена и посевной материал;
- `/udobreniya/` и `/udobreniya-i-khimikaty/` — удобрения и агрохимия;
- `/sredstva-zashhity-rasteniy/` — средства защиты растений;
- `/polevye-raboty/`, `/uborka-urozhaya/`, `/arenda-spetstekhniki/` — услуги и аренда техники.

Парсер разбирает карточки объявлений Agroserver по HTML-структуре: блок `line`, название из `th`, цену из `price`, регион из `geo`. После этого строки фильтруются по ключевым словам, например `дизель`, `пшениц`, `селитр`, `карбамид`, `гербицид`, `вспаш`, `посев`.

Если Agroserver временно возвращает 503 или блокирует запросы с Vercel, система не падает и использует резервные цены из встроенной региональной базы.
