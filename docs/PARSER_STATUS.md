# Статус интернет-парсинга

В проекте реализованы парсеры внешних источников. Для Agroserver добавлены реальные разделы каталога и парсинг карточек объявлений (`div.line`, `div.price`, `div.bl.geo`). Если Agroserver возвращает страницу проверки с капчей (`Введите код, указанный на картинке`), система фиксирует это в журнале и продолжает работу через резервную региональную ценовую базу.

Проверка:

```text
/api/cron/parse-prices
```

Если в ответе по источнику Agroserver указано `Agroserver вернул страницу проверки/капчи`, это означает, что сайт блокирует serverless-запросы Vercel. Это не ошибка расчётного модуля: для стабильной промышленной интеграции нужен официальный API, отдельный серверный парсер с постоянным IP/прокси или ручная загрузка подтверждённых цен.

HeadHunter использует публичный API вакансий и медианную зарплату механизатора. Если API возвращает HTTP 400/403, причина фиксируется в `parser_logs`, а расчёт использует резервную ставку труда.
