# Парсер СПбМТСБ

Добавлен отдельный источник для топлива:

- Источник: СПбМТСБ — территориальные индексы нефтепродуктов
- URL: https://spimex.com/indexes/petroleum/territorial/
- Тип парсера: `spimex_petroleum`
- Материал: Дизельное топливо
- Индекс: `DTL`
- Единица: руб./л, если на странице выбран режим «В рублях за литр»

Парсер ищет в HTML блок:

```html
<div data-graph="DTL" class="indexes-table__cols">...</div>
```

и берёт значение из:

```html
<div class="indexes-table__col index-value">
  <span class="big">...</span>
</div>
```

Если СПбМТСБ отдаёт значение, оно сохраняется в таблицу `price_snapshots` как интернет-цена. Резервная региональная база остаётся включённой, чтобы расчёт продолжал работать при недоступности внешнего источника.
